# International Standard Statistical Classification of Fishing Gear (ISSCFG, 2016)
 
This is a plain-text transcription of the ISSCFG 2016 gear table published by the FAO Coordinating Working Party on Fishery Statistics (CWP), made so that it displays on GitHub. **It is not an official version.** If it differs from the FAO original, the original takes precedence.
 
- **Official source:** [FAO Open Knowledge repository](https://openknowledge.fao.org/items/4de1cb7a-34e3-4645-ae94-0cfc3ef4ad70)
- **Maintained by:** the Coordinating Working Party on Fishery Statistics (CWP). See the [CWP Handbook of Fishery Statistics: fishing gear classification](https://www.fao.org/cwp-on-fishery-statistics/handbook/capture-fisheries-statistics/fishing-gear-classification/en/) for the current status of the classification and how to contact the CWP.
## About the classification
 
- **History.** The ISSCFG was first adopted at the 10th CWP Session (Madrid, July 1980). The current version was adopted at the 25th CWP Session (Rome, February 2016), and is published as Annex M of the CWP Handbook of Fishery Statistics.
- **Updates under discussion.** The FAO repository lists a 2025 CWP meeting document on possible updates to ISSCFG 2016 (CWP-28/2025/Pr.7). Check the CWP pages before relying on this table.
- **Further reading.** He, P., Chopin, F., Suuronen, P., Ferro, R.S.T. and Lansley, J. 2021. *Classification and illustrated definition of fishing gears*. FAO Fisheries and Aquaculture Technical Paper No. 672. Rome, FAO. This gives definitions and illustrations of each gear category.
## Columns
 
- **Gear category:** gear groups are in capitals, followed by the gears within each group.
- **Abbreviation:** the standard abbreviation.
- **ISSCFG code (2016):** the current numeric code.
- **Previous code (1980):** the code in the original 1980 classification. A dash means the gear had no separate code in 1980.
"nei" means "not elsewhere included".
